# Contributing

Thanks for helping keep this list useful.

## Add a program

Please open a PR that updates `readme.md` with one new entry in the most relevant category.

Use this format:

```md
- [Program Name](https://official-link.example.com) - Credit amount / discount, eligibility, and what it covers.
```

## What qualifies

A program should be a startup credit, discount, or partner program from a company offering free or discounted access to its product for early-stage companies (cloud, AI/ML, dev tools, databases, fintech, sales/marketing, compliance, or operations).

## Requirements

Before submitting:

- Use the **official program page** whenever possible.
- Put the entry under the best matching category (add a new category only if none fit).
- Keep descriptions short and factual: amount/tier, eligibility, what's included.
- Do not add affiliate links, referral links, or tracking links.

## Good PR checklist

- [ ] Program link works
- [ ] Entry uses the list format
- [ ] Category is appropriate
- [ ] Description includes credit amount/eligibility
- [ ] No duplicate entry already exists

## Suggest without a PR

If you do not want to open a PR, create an issue with:

- Program name
- Official link
- Category you think it belongs in
- Credit amount and eligibility notes
