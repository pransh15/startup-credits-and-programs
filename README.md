# Startup Credits & Programs

A curated list of startup credit and partner programs: cloud, AI/ML, developer tools, databases, fintech, and more.

## Cloud Infrastructure

- [AWS Activate](https://aws.amazon.com/activate/) - $1K (self-serve)  $100K (Portfolio)  $300K (Gen AI tier) · $1K open to all; higher tiers require VC/accelerator/incubator affiliation · Largest & oldest program. Credits valid ~2 years. Bedrock AI model credits available.
- [Microsoft for Startups Founders Hub](https://www.microsoft.com/en-us/startups) - $1K–$5K (self-serve)  $150K (Investor Network) · $1K–$5K open to all, no VC required · Best self-serve entry point. Includes Azure OpenAI Service, M365, GitHub Enterprise.
- [Google for Startups Cloud Program](https://cloud.google.com/startup) - $100K (Start)  $200K–$350K (Scale tier) · Higher tiers via accelerator/VC partnership · Includes Firebase, AI platform, and 30+ partner perks.
- [Oracle for Startups](https://www.oracle.com/startup/) - $100K OCI credits + 70% discount · Open application · $500 free to start.
- [IBM Cloud for Startups](https://www.ibm.com/cloud) - Varies by region/partner · Partner-referred · watsonx AI access.
- [DigitalOcean Hatch](https://www.digitalocean.com/hatch) - Up to $100K · Early-stage startups · Simpler infra, developer-friendly.
- [Cloudflare for Startups](https://www.cloudflare.com/forstartups/) - Varies (perks bundle) · Accelerator/partner · Workers, R2, CDN, security.
- [Alibaba Cloud Startup Catalyst](https://www.alibabacloud.com/) - Up to $120K · Open application · Strong for APAC.
- [Scaleway](https://www.scaleway.com/) - Varies · EU-focused programs · European data residency.
- [Vultr](https://www.vultr.com/) - Up to $120K · Startup program · GPU instances + storage.
- [Akamai (Linode) Rise](https://www.linode.com/) - Varies · AI/startup program · Offers GPU instances.
- [Nebius for Startups](https://nebius.com/startups) - Nebius · $5,000 AI credits + discounts on GPU compute
- [OVHcloud Startup Program](https://startup.ovhcloud.com/) - OVHcloud · €10,000 for Start level; up to €100,000 for Scale level, plus technical support
- [Render](https://render.com/startups) - Render · Up to $100,000 in credits
